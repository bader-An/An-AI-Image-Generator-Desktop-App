# AI Image Generator Desktop App

A text-to-image application built using a pretrained **Stable Diffusion** model.

## 📌 About

This project generates images from text prompts using Stable Diffusion. Describe what you want to see, and the model creates an image based on your description.

## 📂 Dataset

This project uses a dataset hosted on Kaggle (too large to store directly in this repository):

🔗 [Realistic Vision Dataset on Kaggle](https://www.kaggle.com/datasets/baderan/realisticvision)

To use it:
1. Download the dataset from the link above
2. Extract it into a folder named `data/` in the project root (or update the path in the code to match wherever you place it)

## 🚀 Getting Started

### Prerequisites
- Python 3.9+
- pip

### Installation

```bash
git clone https://github.com/bader-An/An-AI-Image-Generator-Desktop-App.git
cd An-AI-Image-Generator-Desktop-App
pip install -r requirements.txt
```

### Usage

```bash
python main.py
```
